# Archive

## 2015-label-tool

The original `plone.github` tool, started in 2015 by Jens W. Klein and the
Plone Core Developer team. Its `manage_labels` script (buildout-based,
`src/plone/github/`) created and migrated the numbered label scheme
(`01 type: bug` … `53 target: major`, `99 tag: …`) across the repositories
listed in `definitions.json`. It was last run on 2019-10-26.

It is kept here unchanged for reference. The 2026 proposal in
[`../proposal/`](../proposal/) supersedes both the scheme and the tool.

## google-sheet

The Google Sheet "Github Plone Organisation Labels"
(https://docs.google.com/spreadsheets/d/1IQ73bSQ10b0pwoUFn0u8SE4epDdvwjhTiYTDyPAhx7A/edit?gid=0)
was the human-readable definition of that scheme. The PDF and CSV here are
the sheet exactly as exported on 2026-11-05, including the
`06 type: accessibility` row that was proposed in 2026 and never rolled out,
and the sheet's own `51: target:` colon typo.
